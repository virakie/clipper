# Clipper

A tiny always-on replay buffer for Windows. It quietly keeps the last couple of
minutes of your screen or game, and one key press saves them as an `.mp4`. Think
"OBS replay buffer" without OBS: a ~550 KB native app, about 60 MB of RAM while
recording.

## Features

- **One key to save**: `Shift+F3` saves the last 2 minutes (length is up to you,
  up to 15 min) and plays a chime when the file is written.
- **Sources**: any monitor (Main, Second, Third... detected automatically), or
  **Game** mode, which finds the fullscreen game in front and records only that
  game's sound, so music or podcasts playing in the background stay out.
- **Mic** mixed into the clip, with its own volume.
- **Trimmer** (scissors button): drop a clip in, set in/out points (`I` / `O`,
  arrow keys step one frame), preview in the window, and export to a target size
  (20 MB by default, handy for Discord). Picks resolution, frame rate and bitrate
  for you; AV1 by default, H.264 if you need it.
- **Shortcuts you can change**: `Ctrl+Alt+C` shows / hides the window. Change
  both in the menu, under Shortcuts.
- **Portable**: one exe; settings live in `clipper.ini` next to it.
- Clips are named like screenshots: `GameName_261030-213012.mp4` in Game mode,
  `Clip_261030-213012.mp4` otherwise.

## Requirements

- Windows 11 (tested). Windows 10 should work but hasn't been tried.
- An **NVIDIA GPU** (recording uses the NVENC hardware encoder).

## Install (portable)

1. Download `Clipper-x.y.z-win64-portable.zip` from [Releases](../../releases)
   and unzip it anywhere (a USB stick works too).
2. Run `clipper.exe`. A red dot appears in the tray; the window opens with
   `Ctrl+Alt+C`.

Everything stays in that folder: settings (`clipper.ini`), logs, scratch files
(`temp`) and your clips (`Clips`, or pick another folder in the menu). Move or
delete the folder and Clipper is gone. The only things it touches outside are
the tray icon's "always show" flag, and the Windows startup entry if you turn
on menu > Start with Windows.

The portable zip includes ffmpeg 8.1.1 (GPLv3, full build from
https://www.gyan.dev/ffmpeg/builds/, source at https://ffmpeg.org/download.html).
Already have ffmpeg 8.0+? The small `Clipper-x.y.z-win64.zip` is just Clipper;
it uses `ffmpeg.exe` next to it, then scoop's, then the one on your PATH.

## Command line

```
clipper.exe --mode main|second|third|game|off   pick what to record
clipper.exe --show | --toggle | --save | --quit
clipper.exe --trim "C:\path\clip.mp4"           open a clip in the trimmer
clipper.exe --hotkey "save Ctrl+F9"             change a shortcut (save / window, or off)
```

A second launch passes these to the running Clipper.

## Build

```
cargo build --release
```

Rust (edition 2024). The icon is generated by `assets/make_icon.py`.
